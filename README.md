# AHLAM IT POS Transaction Manager — MVP

## Project title
POS Transaction Management Web Application

## Problem
POS operators need a simple way to record transactions and see totals without relying only on notebooks.

## MVP solution
A responsive web application that provides:
- Simple login
- Create transactions
- View transactions
- Update transactions
- Delete transactions
- Search transactions
- Total transaction count
- Total amount
- Cash-in and cash-out totals
- Browser storage
- Logout

## Demo login
Username: `admin`
Password: `1234`

> Note: This is a learning/demo authentication system. It is not suitable for protecting real financial data because the credentials are stored in the front-end code.

## Technologies
- HTML5
- CSS3
- JavaScript
- Browser localStorage/sessionStorage

## How to run
1. Put all three files (`index.html`, `style.css`, `app.js`) in the same folder.
2. Open `index.html` in a browser.
3. Login with the demo credentials.
4. Add, edit and delete transactions.

## How to deploy
This project is a static website, so it can be deployed using GitHub Pages, Netlify, or another static hosting service.
